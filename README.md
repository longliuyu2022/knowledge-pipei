# 同知

**因问题相聚，以知识相识。**

同知把「同题」的问题型知识社群与「同频」的知识画像、伙伴匹配合并到一个应用。用户带着具体问题参与讨论，留下有来源的阶段成果，再与值得深入交流的人建立连接；也可以先认识自己的知识兴趣，找到合适的小组与伙伴。

正式入口：**https://zhihu.aiimage.icu** · 管理后台：**https://zhihu.aiimage.icu/admin**

版本 `2.0.0`。独立目录 `/root/xiangmu/zhihu-tongzhi`，独立服务、数据库和会话。源码保存在原授权仓库的 [`tongzhi` 分支](https://github.com/longliuyu2022/knowledge-pipei/tree/tongzhi)，保留原 `main` 分支。

## 已实现的主流程

- **同题问题小组：** 按问题或知乎问题链接发现小组；选择 24 小时、7 天或持续参与；讨论、回复、添加来源、低频 AI 主持；轮次推进、结论与分歧整理、人工核对、版本记录和 Markdown 导出。
- **知识画像：** 用自选兴趣、自述和主动导入的知乎摘要生成知识名片，提供七部分知识报告、证据与覆盖说明、历史快照和分享卡。兴趣不被解释成专业能力或人格诊断。
- **异步同频：** 点击开始后在后台寻找真实参与者，无需同时在线；等待、暂停、取消、有效期和通知持久化；双方确认才建立一个私聊连接。
- **知识破冰：** 私聊先显示本地话题；双方分别同意后，自动基于共同兴趣、问题与知乎搜索摘要生成深入话题，保留原文链接。话题加入草稿，由本人发送。
- **自我认知：** AI 知识伙伴、与自己对话；选择本人发言后生成待确认的兴趣建议，不自动扫描聊天或悄悄改画像。
- **治理与后台：** 邮箱及知乎登录、匿名昵称、屏蔽、举报、AI 辅助语境审核、人工警告/禁言/停用及申诉。独立后台查看注册、画像、匹配与小组统计，按案件审计读取必要内容。

通知目前是持久化的**站内通知**。知乎网站内的一键加入按钮需要浏览器扩展或平台支持，当前使用站内问题卡和粘贴问题链接；扩展、Web Push 与多实例部署属于后续工作。

## 本地运行

需要 Node.js **22.16+**。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

页面：`http://127.0.0.1:5178`；API：`http://127.0.0.1:3033`。不配置凭证也可本地使用规则画像、小组和匹配；模型与知乎调用会明确说明未配置。

生产构建及运行：

```bash
npm run build
npm start
```

模型使用兼容 Chat Completions 的服务端配置。当前线上沿用 `https://metapi.lilililwan.xyz/v1` 与 `deepseek-v4-flash`。App Key、Access Secret、模型密钥和管理员密码哈希均通过服务器私有文件及 systemd Credentials 提供，不写入浏览器、Git 或部署文档。

知乎 App ID 为 `400`，用户已确认登记回调 `https://zhihu.aiimage.icu/auth/callback`。新域名授权入口、状态校验和回调自动化检查通过；最后的真实授权确认需开发者本人完成，见 [验证记录](docs/VALIDATION.md)。

## 验证

```bash
npm test
npm run build
npm run test:browser
```

当前后端 **191/191** 通过；五套浏览器验收共 **68/68** 通过，覆盖桌面及 390/320 px。自动化使用隔离数据库与明确的测试身份，不往生产匹配池放入演示人物。

迁移工具支持一致性备份、预演、导入、引用校验与安全重跑。当前已从两站快照迁入 22 个账号、4 个历史问题小组和相关内容，79 条来源映射及 99 处引用校验通过。来源时间为 **2026-09-13 17:25:31（Asia/Shanghai）**，旧站继续独立运行，后续写入不自动同步。旧会话及 OAuth 令牌不迁移；未绑定身份的访客不能仅凭昵称认领旧数据。
