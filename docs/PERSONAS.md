# 12 种人格名片

人格采用 4 种核心追求 × 3 种连接方式的分类，个人页只展示本人选择的类型，不展示其他类型图鉴。画像向导的交流偏好步骤可选填两个方向，保存后称号与 PNG 卡片使用对应的角色名称、一句话自画像与三个关键词。清除选择后恢复原有兴趣称号。

分类是用户主动选择的自我描述，不是心理测评。已有画像不自动归类；仅选一项时也不会生成类型。画像保存成功后自动弹出本人的 PNG 人格卡，可关闭后通过“分享人格卡”再次打开。分享支持图片下载、文案复制和设备原生分享；微信/朋友圈提供图片下载及操作提示，知乎/小红书提供文案复制及配图提示，不自动发布。每种类型提供价值关注、关系偏好、优势、盲点、内在拉扯和行动提示；本人解读额外关联当前画像中的兴趣与交流偏好，并明确区分类型提示与事实依据。

定义与解读位于 `shared/personas.js`，界面位于 `src/PersonaExplorer.tsx`，样式位于 `src/persona.css`。原有 `shared/catalog.js` 和 `src/styles.css` 无需修改。

`POST /api/profile` 的 input 新增两个可选字段：

- `personaDrive`：`truth`、`explore`、`empathy`、`create`。
- `personaConnection`：`solo`、`duo`、`group`。

无效值返回 `400 invalid_persona`。旧客户端省略字段仍可保存。AI 可以生成兴趣解读，但不会覆盖已选类型的称号。人格类型不参与匹配分数计算。

验收：`npm run build`、`npm test`、`npm run test:browser`。测试覆盖 12 种组合、旧输入兼容、非法输入、AI 称号保留、保存与清除、自动弹窗、分享降级、刷新保留和 PNG 下载。
