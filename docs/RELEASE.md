# 同知 2.0.0 交付范围

同题与同频已合并为新目录 `/root/xiangmu/zhihu-tongzhi`，正式运行在 `https://zhihu.aiimage.icu`。本文件描述已实现范围；最初的产品与实施方案保留为设计依据。

| 用户提出的方向 | 当前实现 |
| --- | --- |
| 1 问题驱动 | 首页以具体问题和知乎问题链接发现小组，提供问题、目标、阶段；知乎原站内的按钮待扩展或平台支持 |
| 2 社群生命周期 | 24h、7d、持续参与，随时退出，招募/讨论/核对/完成/归档/休眠状态与独立轮次 |
| 3 用户分层 | 公共问题概要、成员讨论；成员分别开启邀请许可后，接受邀请才私聊 |
| 4 AI 主持适度参与 | 手动整理、追问、成果草稿与可选低频自动总结，不自动频繁 @ 潜水者 |
| 5 阶段成果 | 讨论总结、结论、分歧和资料引用，核对者署名、乐观版本冲突、历史修订和 Markdown 导出 |
| 6 两条路径互通 | 画像推荐问题小组，小组成员可发起深入交流邀请 |
| 7 知识人格差异化 | 基于显式兴趣、问题、目标和交流方式，解释共同点；不作为心理测评或恋爱匹配 |
| 8 认识自己 | 画像分享卡、七部分知识报告、依据及覆盖提示；无足够跨期材料时保留未知 |
| 9 异步匹配 | 七天请求、最长48h提案、持久队列、暂停/取消、双确认、站内通知；无需同时在线 |
| 10 AI 深入破冰 | 两人分别授权后自动生成具体问题、证据比较和可合作的小验证 |
| 11 知乎原文关联 | 破冰附官方搜索摘要与原文链接，来源标识校验，不把摘要说成全文 |
| 12 AI 伙伴与自我对话 | 明确标注AI，单独会话、草稿与重试幂等、删除、规则回退和当前画像范围 |
| 13 匿名与安全 | 站内昵称、默认少暴露头像/邮箱，双确认，文字交流，无照片上传入口，屏蔽与举报 |
| 14 多层治理 | 行为频率、语境AI审核、风险待复核、人工警告/24h禁言/停用、申诉与审计 |
| 15 授权优化画像 | 单独开关、仅本人选中消息、待确认建议、撤回/隐藏/删除后失效；已接受兴趣可自己编辑移除 |
| 16 人与社群共同推荐 | 本地知识兴趣解释用于同频提案与同题推荐，小组交流继续转入私聊 |

统一管理后台支持邮箱/知乎/访客筛选、知识画像、参与统计、异步匹配状态、账号处置、小组举报，以及按案件填写理由后读取必要内容。原同频管理员密码哈希保留。

底层为 React 19 + TypeScript + Vite、Express 5、Node SQLite 与 SSE。所有模型功能共用每分钟五次请求、最多两个并发的预算；高频环境下会出现规则回退或风险待审核，不宣称每条消息均得到模型判断。

## 尚未作为本版能力交付

知乎网站内注入按钮、Web Push/邮件通知、embedding 真人匹配和多实例共享队列尚未启用。邮箱未做所有权验证，也未接邮件找回；`notificationDigests` 只保存偏好，尚未投递定时摘要。没有足够数据时不会生成长期趋势、能力结论或虚构在线伙伴。

旧内容按明确来源导入历史轮；不能恢复的旧成果版本不伪造，无法核验新授权边界的旧 AI 输出默认隐藏。源库以独立快照迁入，旧站之后的写入不自动同步。详情见 [MIGRATION.md](MIGRATION.md) 与 [PRIVACY.md](PRIVACY.md)。

知乎新域名的真实授权最终确认由开发者本人完成，状态单列于 [VALIDATION.md](VALIDATION.md)。
