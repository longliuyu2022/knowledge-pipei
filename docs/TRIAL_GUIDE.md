# 真人试用与双人演示

体验入口：<https://zhihupipei.aiimage.icu/#pairing>。先邀请 5–10 位愿意参与的朋友，在约定的 20 分钟内一起在线。下面的邀请文案已备好，尚未替你向任何人发送邀请。

## 可直接发送的邀请

> 我做了一个知乎黑客松作品「同频」，想请你花 5 分钟试用：从你的兴趣找到一个可以聊得来的人。打开 https://zhihupipei.aiimage.icu/#pairing ，先创建知识画像，再点击「开始配对」。遇到伙伴后，双方确认就能聊天。欢迎告诉我哪里难用，以及推荐的话题是否自然。

发出邀请时补上实际约定时间。配对页的「邀请朋友一起配对」也可复制公开链接，手机可使用系统分享。邀请链接不会指定配对对象；排队用户较多时，朋友可能遇见其他参与者。

## 开始前

1. 负责人先连接自己的知乎账号，在「导入知乎兴趣 → 检查知乎数据连接」勾选读取范围并运行检查。五项成功或空数据可继续；错误应按页面说明处理。收藏夹为空时，收藏夹内容按空数据记录，不虚构收藏夹。
2. 检查和导入共用知乎读取额度。完成检查后，按倒计时等待，再选择自己愿意导入的数据；不重复点击请求。导入后看一次画像，确认摘要符合自己的兴趣。
3. 管理员可到 `/admin` 看用户详情中的检查记录、导入条数与画像。访客数量包含自动创建的浏览器身份，不能拿总用户数当作真实报名人数。

## 试用任务（每人约 5 分钟）

| 环节 | 参与者操作 | 观察的问题 |
| --- | --- | --- |
| 认识自己 | 选 3–8 个真实兴趣，写一个想聊的问题并生成画像 | 能否不经讲解完成？画像是否贴合？ |
| 主动相遇 | 打开灵魂匹配，查看实际人数，点击开始 | 是否理解自己正在等人、可以取消？ |
| 双方选择 | 查看候选，选择聊一聊或换一个 | 是否明白确认前没有聊天？ |
| 第一句话 | 在聊天中选一条话题，编辑草稿后发送 | 话题是否具体自然？原草稿是否保留？ |
| 来回交流 | 双方各回应至少一句 | 是否有继续交流的意愿？是否卡顿或丢消息？ |
| 结束 | 试用数据与隐私中的导出、退出或屏蔽入口 | 是否能找到管理自己资料的方式？ |

每位参与者完成后只问三件事：最不清楚的一步是什么、哪句话题最愿意回应、是否愿意再用一次。问题记录用参与者代号即可，不收集私聊正文。

## 双人录屏准备

请两位参与者使用自己的设备或独立浏览器身份，在队列较空的时间一起演示。提前检查网络、画像和知乎连接；服务部署重启后，OAuth 与未完成队列需重新开始，已建立聊天仍保留。

按 [三分钟演示脚本](../DEMO.md) 录制：实际排队、双方确认、聊天共同兴趣、选择开场进入草稿、双方发送、刷新保留。若两位参与者已经有连接，他们不会再次被配到彼此；可展示既有聊天，或另约未连接的参与者演示首次匹配，不删除真实历史来伪造首次相遇。

录屏中的公开页面与测试资料可用于演示；个人授权的最终确认由参与者自己操作。正式提交前用实际录制内容核对文案，说明哪些是真实线上效果、哪些是隔离测试材料。
