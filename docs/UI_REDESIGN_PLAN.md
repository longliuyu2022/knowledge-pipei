# 同知网页美化方案

确认日期：2026-09-14。

状态：已按确认方案完成第一版页面改版，进入部署与用户体验反馈阶段。

## 目标与定位

以“先认识自己，再找到同频的人”为主要使用路径，将知识人格和同频匹配作为两个重点入口。解决当前字体偏小、文字过多、信息重复、重点功能不突出以及聊天空间不足的问题。

沿用现有业务逻辑与数据结构，通过导航、信息层级、排版和交互布局改善体验。保留问题小组、知识报告、AI 陪伴及账号管理等已有功能。

## 视觉风格

主色改为与知乎一致的蓝色方向，以知乎蓝 `#056DE8` 为主要品牌色，替换当前紫色强调样式。页面采用浅色背景、白色面板、清晰的文字层级和充足留白。

建议颜色变量：

| 用途 | 颜色 | 使用方式 |
| --- | --- | --- |
| 品牌蓝 | `#056DE8` | 品牌强调、选中状态和重点元素 |
| 操作蓝 | `#0563D6` | 白字主按钮，保证文字对比度 |
| 深蓝 | `#0456B8` | 按钮悬停、强调链接 |
| 浅蓝 | `#EAF3FF` | 选中背景、本人聊天气泡、轻量提示 |
| 页面背景 | `#F6F8FA` | 全站背景 |
| 内容面板 | `#FFFFFF` | 卡片、聊天区、弹窗 |
| 主文字 | `#172B4D` | 正文、标题 |
| 辅助文字 | `#596579` | 时间、说明、次级内容 |
| 边框 | `#DFE5EC` | 分隔线和输入框边界 |

成功、警告与错误保留各自语义色。选中状态同时使用文字、边框或图标表达，避免仅靠颜色区分。实施时检查文字对比度与键盘焦点可见性。

## 字号与排版

- 正文以 17px 为主，辅助文字为 14–15px，按钮文字为 16–17px。
- 页面标题为 28–32px，人格名称为 36–44px；手机端按可用宽度适当缩小。
- 正文行高约 1.6，长文本控制行宽，避免横跨整个桌面页面。
- 减少小标签、装饰图标、重复标题和卡片嵌套，增加模块间留白。
- 每页突出一个主要操作，次要操作使用次级按钮或文字入口。

## 导航与页面重点

主导航顺序为“知识人格、同频匹配、消息、问题小组”；知识人格作为默认首页。“我的同题”收纳到问题小组内部，AI 陪伴保留独立可访问入口，账号与设置收纳低频操作。已有深链继续可用。

| 页面 | 首要内容 | 主要操作 |
| --- | --- | --- |
| 知识人格 | 人格名称、一句话描述、三个关键词 | 寻找同频伙伴 |
| 同频匹配 | 匹配状态或当前推荐伙伴 | 开始匹配／查看并确认连接 |
| 消息 | 会话与消息记录 | 发送消息 |
| 问题小组 | 相关问题和参与中的讨论 | 查看或参与讨论 |
| 账号与设置 | 账号、偏好、授权和隐私管理 | 按具体设置操作 |

## 知识人格首页

已有画像时，首屏突出人格名称、一句话描述和三个关键词。主按钮为“寻找同频伙伴”，次按钮为“编辑人格”和“分享名片”。

下方展示简短人格解读；六项详细解读、兴趣雷达、知识报告、来源依据和成长记录通过明确的展开入口或标签页访问，避免同时铺满页面。保留“供自我探索参考”的简短说明。

首次进入、尚未创建画像时，提供“从知乎导入”和“手动创建”两种清晰入口。已有画像但未选择人格的用户看到补充选择入口，不自动推断人格。

## 同频匹配页

按状态组织页面，优先呈现当前可执行的操作：

1. 未开始：简要说明匹配方式，突出“开始匹配”。
2. 寻找中：显示真实状态以及暂停、取消入口。
3. 已暂停：突出“继续寻找”。
4. 找到伙伴：突出一张人物卡，优先显示共同兴趣、交流方式和简短推荐理由，再由用户确认连接。
5. 已连接：提供进入聊天入口。

算法说明、评分细项和重复提示默认收起。保持双方确认后建立私聊的现有规则，状态数据使用后端真实结果。

## 大面积聊天布局

覆盖伙伴私聊与 AI 陪伴页面。

- 桌面端：聊天面板占主内容区宽度约 75%，最低不少于 70%；会话列表占约 25%。这里的比例指完整聊天面板，包括消息记录与输入区，而非单独输入框。
- 整个聊天工作区尽量铺满屏幕可用高度；消息列表内部滚动，输入区保持可见。
- 输入框默认约 3 行，随输入增长到约 6 行，超过后内部滚动；消息正文使用 17px。
- 手机端：进入会话后聊天区占满内容宽度，通过返回进入会话列表；适配虚拟键盘和底部安全区。
- 破冰推荐收纳为输入框上方的可展开入口，选择后仍加入草稿，由本人发送。
- 人物详情放入侧边抽屉，手机端使用适合小屏的详情面板。
- 保留发送中、失败重试、草稿、未读、举报及必要授权状态；调整布局时不改变现有发送与授权规则。

## 内容精简原则

删除重复口号、重复导航说明和不帮助当前操作的常驻长文。简短提示就近放置；详细解释使用展开区域，标签应能说明其中内容。

必要授权、隐私与数据用途说明保留在对应操作处。低频技术说明移入帮助或设置，重要错误和需用户处理的状态保持可见。

## 实施顺序

1. 建立统一蓝色、字号、间距与按钮样式；调整导航，知识人格成为默认入口。
2. 重做知识人格和同频匹配的信息层级，突出主要操作。
3. 扩大伙伴私聊和 AI 陪伴聊天区，完成桌面及手机适配。
4. 精简其他页面文案，统一卡片、留白与交互样式。

## 完成标准与交付

- 首屏能直接识别知识人格与同频匹配两个重点入口。
- 主要正文达到 17px，辅助信息清晰可读，页面不因增大字号出现溢出或遮挡。
- 人格详细报告默认收起，保留明确访问入口。
- 桌面聊天面板至少占主内容区 70% 宽度，消息记录拥有主要可用高度。
- 手机聊天占满内容宽度，输入框不被键盘或固定导航遮挡。
- 全站采用统一蓝色系，原有功能、用户数据及深链继续可用。

第一版已完成蓝色主题与字号调整、知识人格默认入口、详情折叠、匹配重点突出、问题小组内部导航，以及私聊和 AI 聊天布局扩大。人物详情继续使用现有详情弹窗；移动端虚拟键盘下的体验待用户实机反馈。按用户偏好完成构建与必要运行检查，页面体验由用户测试。
